## About Me

Software Engineer and First Class Honours Computer Science graduate from the University of Westminster, based in Colombo, Sri Lanka.

- Researching and building in **AI Safety and LLM Red Teaming** -- creator of **MIMIC**, an automated semantic mutation framework evaluating frontier model guardrails.
- Commercial full-stack experience delivering production microservices, event ticketing platforms, and scalable web applications.
- Core languages and runtimes: **Python**, **TypeScript / JavaScript**, **Kotlin**, and **SQL**.

## Featured Projects

### [MIMIC: Modular Semantic Mutation Engine for LLM Red Teaming](https://github.com/dillon-sj/mimic-llm-redteaming)
* **First Place, Best Final Year Project in Computer Science** at PROJEXPO (IIT CuttingEdge '26).
* **National ICT Awards (NBQSA) 2026 entrant** (Tertiary Technology).
* Automated 3-stage generative mutation framework elevating adversarial attack success rate from 17% to 66% (3.9x gain).
* Features a high-concurrency AsyncIO engine, multi-provider ModelAdapter abstraction (Gemini, Groq, Mistral, OpenRouter), and automated LLM-as-a-Judge validation layer (Cohen's kappa = 0.75).
* Evaluated against NIST AI Risk Management Framework (NIST AI RMF 1.0) standards.

### [Bioacoustic Ecological Monitoring: Deep Learning for Wildlife Audio Classification](https://github.com/dillon-sj/bioacoustic-wildlife-monitoring)
* End-to-end passive acoustic monitoring and classification pipeline in Python.
* Extracts 2D Log-Mel Spectrograms using Librosa (22,050 Hz sampling rate, 5.0s windowing).
* Custom 3-layer Convolutional Neural Network (CNN) in TensorFlow achieving **89.0% test accuracy** and **0.92 F1-score** on unseen test data.
